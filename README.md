# Claude Code Team Primer

A browser-based slide deck for a ~30-minute Claude Code intro talk delivered to a CapTech team onboarding to a GraphQL-heavy client project. Published publicly afterward as a reference.

## Run the presentation

```bash
cd slides
./rundeck
```

That opens the deck in Chrome and starts a local server. Speaker notes stream to the terminal as you navigate.

**Navigation:** arrow keys or space to advance, `Esc` for overview, `F` for fullscreen, `S` for an in-deck notes overlay.
