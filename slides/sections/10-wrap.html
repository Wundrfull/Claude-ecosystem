How sessions run

MCPs & CLIs

What plugs in

  • Playwright MCP, Obsidian MCP.
  • Frame0 CLI, Supabase CLI.
  • Vercel CLI, Redis CLI.
  • Some MCPs became CLIs — cheaper on tokens.

None of this is required. All of it compounds.

  • 60 seconds.
  • The shape: Claude Code alone is powerful; the surrounding tooling is what makes it sustainable.
  • Three categories:
    • Pay-for models: Claude Pro x20 and Codex Pro x20 side by side. Anthropic API for skill dev.
    • Orchestration: Agent Teams (Opus lead, Sonnet teammates), Agent SDK, tmux, git worktrees.
    • Plugs: MCPs for tools Claude must hold state over (Playwright, Obsidian); CLIs for one-shot calls (Frame0, Supabase, Vercel, Redis).
  • Call out the token story: some tools shipped as MCPs first, then added CLIs. CLI form is cheaper because you pay for one call instead of sustained MCP context.
  • Goal is name-recognition, not a tutorial.
