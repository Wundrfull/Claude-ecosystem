every slash command anthropic ships · my personal ranking

The short list, in order of how often I reach for it.

  1. 01/clearBetween unrelated tasks. Biggest accuracy lever you have.
  2. 02Shift+TabPlan Mode. Read-only scouting before any real change.
  3. 03/rewindWhen you're down a wrong path. Four actions to pick from.
  4. 04/permissionsAudit what Claude can do in this repo. Check before every client session.
  5. 05/compactLong related session, approaching the wall.
  6. 06/memoryView or edit MEMORY.md. Skim weekly.
  7. 07/contextRead-only snapshot. Use when unsure whether to clear or compact.
  8. 08/reviewSelf-review before requesting human review.
  9. 09/security-reviewAny diff touching auth, data, secrets, or infra.
  10. 10/configModel selection, theme, output format. Set once.
  11. 11/helpResurfaces the list when a command name escapes you.
  12. 12/initBootstrap CLAUDE.md. Mostly useful on greenfield repos.

Your ranking will differ. Keep the top five in muscle memory; look up the rest.

45 seconds. Say "my ranking, not The Ranking" up front. The top five are the ones I could not work without.

Stress: /clear over /compact for most tasks. /compact bakes in whatever direction the session was headed; /clear starts you fresh, which is usually what you actually want.

Point at /permissions: this is the one everyone forgets. Run it before you touch a client repo. Know what Claude is allowed to do before you ask it to do anything.

beyond the CLI

Tools I actually use with Claude Code.

Agent orchestration

Teams & subagents

  • Opus 4.7 lead with Sonnet 4.6 teammates for parallel work.
  • Explore agent for read-only scouting without polluting main.
  • Plan agent when the design needs alignment before coding.
  • Agent SDK to build custom subagents for recurring tasks.

Shell & workflow

Terminal layer

  • tmux to keep the Claude session pinned while code runs beside it.
  • git worktrees so agents can work on isolated branches in parallel.
  • gh cli for PR, issue, and check management inside the session.
  • starship prompt for a visible model/context indicator.

Platform & extensions

Plugs into Claude

  • MCP servers for Linear, GitHub, Postgres, Slack.
  • Hooks in .claude/settings.json for deterministic gates.
  • Skills marketplace — install, don't rewrite.
  • AWS Bedrock routing for client engagements.

None of this is required. All of it compounds.
