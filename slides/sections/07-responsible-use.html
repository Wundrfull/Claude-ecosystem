Rule 2 · cite the line

Cite the line — your best hallucination guard.

Ask Claude where something lives before you ask what it does. It will grep the repo, open the file, and answer with a path:line. Hallucinations drop because the model has to point at real code.

~/client/subgraph · opus 4.7
$ where does the token refresh happen?
reading src/auth/refresh.ts:42-78
refreshToken() calls POST /api/auth/refresh with the stored refresh_token
rotation is handled by SessionStore.rotate() — schema/auth.graphql:12
cite: src/auth/refresh.ts:54

Same pattern for /review, /security-review, and any grep-heavy task. No citation, no trust.

60 seconds. Lead with the accuracy claim, not the process. "Cite the line" is the highest-ROI habit on this slide because it forces Claude to grep before answering, and grep-then-cite is measurably more accurate than guess-then-write.

Walk the terminal: question, file read, symbol explanation, line citation. That is the shape of a correct answer. When the team sees a claim with no path:line, they reject the diff and ask for the citation.

Rule 3 · gate your tools

Gate your tools before you need to.

Three layers, loosest to strictest. Stack them; do not pick one.

/permissions

Approve safe tools once per repo. Deny-by-default for anything destructive. Stops the mid-task Approve spam without opening the barn door.

allowed-tools:

Per-skill allowlist in the skill's frontmatter. A /security-review skill should not need Bash; say so. Scopes capability to the job.

hooks (PreToolUse)

Deterministic shell gates for anything you can never tolerate. Block git push --force, rm -rf, writes outside the repo. Runs before Claude sees the tool call.

CapTech sandbox: permissive. Client repos: strict — read CLAUDE.md, confirm /permissions, then verify the hook fired.

60 seconds. Stack the three layers as you walk them. /permissions is the everyday lever; allowed-tools in frontmatter is the per-skill scope; hooks are the floor the model cannot cross.

Emphasis: CLAUDE.md can request a behavior but cannot enforce it. Hooks enforce. If a rule matters for compliance, it belongs in .claude/settings.json, not CLAUDE.md.
