90 seconds. Head off the obvious objection first: modern Copilot runs Claude and GPT-class models too, and can draft whole PRs. The difference here is not the model underneath — it is the interaction loop around it.

Left: Copilot lives inside the editor, in one file at a time. It suggests; you accept or reject each step. You stay in the driver's seat at every keystroke.

Right: Claude Code lives in the terminal. You give it a goal. It plans, touches many files, runs the shell, runs tests, and reports back. You gate the task, not every line.

Land on the caption: accept / reject becomes plan / act / verify. Exit: "The shape of that right-hand loop is the next slide."
