What Claude Code is
(and isn't)

Reset the mental model from inline completion to agentic loop. The single most important concept shift for this room.

The mental-model shift

Copilot is not the model

Copilot

A very fast tab-complete with taste.

  • You type. Ghost text appears.
  • Accept or reject, one buffer.
  • No state beyond the visible window.

Claude Code

An agent, not a completion engine.

  • You delegate. It plans, reads, edits, runs, reflects.
  • Operates across the codebase, not one file.
  • Persists across sessions through CLAUDE.md and memory.

The agent loop

Plan → Tool use → Observe → Plan → Done

Claude iterates until done. Your job is to shape what it sees, what it can do, and how it checks itself.
