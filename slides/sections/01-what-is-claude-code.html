What Claude Code is
(and isn't)

Reset the mental model from inline completion to agentic loop. The single most important concept shift for this audience.

The model you know

Copilot

  • Engineer types. Ghost text appears.
  • Accept or reject, inline.
  • Single file, single buffer.
  • No state beyond a few lines of context.

Think: a very fast tab-complete with taste.

30 seconds. Keep it short. The audience already lives here.

The model you are moving to

Claude Code

  • You delegate a task. It plans.
  • It reads files. It edits files. It runs commands. It reflects. It iterates.
  • Operates across the codebase, not one file.
  • Lives across sessions through CLAUDE.md and memory.

An agent, not a completion engine.

Client-ready

90 seconds. This is the reset. Land it before the motion clip.
