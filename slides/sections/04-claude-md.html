The five-line CLAUDE.md

Treat it like a constitution, not a README.

  • Before writing code, state the plan.
  • Never run git push --force without explicit confirmation.
  • If a test was passing and now fails, stop and ask before modifying the test.
  • When unsure, ask one question rather than guessing.
  • Do not add dependencies without asking.

Anthropic recommends under 200 lines. Review it like code.

60 seconds. Read the five lines aloud. Pause between them. These are the lines that show up in nearly every public CLAUDE.md I sampled — anthropics/claude-code, cloudflare/agents, obra/superpowers, langchain.

Frame: CLAUDE.md is a behavior contract. Forbidden phrases, precedence rules, escalation triggers. Not documentation. Version it in the repo, review it like code.
