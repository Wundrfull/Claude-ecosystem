Never edit generated files by hand.

gqlgen regenerates generated.go from schema.graphql on every run. Hand-edits get clobbered silently — and the symptom shows up as a random bug three files away.

The rule, as it lives in CLAUDE.md

CLAUDE.md · line 14
## Codegen
- Never edit generated files by hand.
    Regenerate with:
    `go run github.com/99designs/gqlgen generate`
    Forbidden paths:
    - graph/generated.go
    - graph/model/models_gen.go

Without the rule

~/client · next regen
$
generated.go rebuilt from schema.graphql
hand-edits in generated.go: overwritten
tests pass. prod surfaces the bug next Tuesday.
  • 45 seconds. Three beats.
  • One: gqlgen is the GraphQL codegen tool this client uses.
    • Every schema change, run go run github.com/99designs/gqlgen generate.
    • It rewrites generated.go and models_gen.go from schema.graphql.
  • Two: if Claude or a human hand-edits those files, the edit gets clobbered silently on the next regen.
    • Symptom surfaces later as a bug three files away — expensive to chase.
  • Three: this one line — "never edit generated files by hand" plus the regen command — goes in every engagement CLAUDE.md before anything else.
  • Same rule travels to any gqlgen, protobuf, or OpenAPI codegen project.
  • Say go run github.com/99designs/gqlgen generate twice out loud so the team hears it.
