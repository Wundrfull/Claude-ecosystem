Toggle with Shift+Tab. Open the plan in your editor with Ctrl+G before you run it.

  • 45 seconds.
  • Recommended default for anything touching more than one file.

Anthropic: "Use /clear frequently between tasks to reset the context window entirely."

  • 60 seconds.
  • Every file Claude reads, every command output, every turn piles up in the context window.
  • Performance degrades as it fills.
  • /clear gets you a fresh session without relaunching.
  • Rule of thumb: after two failed corrections on the same issue, clear and rewrite the prompt with what you just learned.
  • Clean context beats a stack of corrections.

Summarize the conversation to free context while keeping the decisions. Pass optional instructions to bias what the summary preserves.

/clear wipes. /compact summarizes. Pick based on whether the next task is related to the last one.

  • 45 seconds.
  • Key distinction: /clear wipes everything; /compact preserves a summary.
  • Use /compact when the work is related and you need continuity.
  • Use /clear when it is not.
  • The optional instructions argument is underused.
  • Example: after 20 turns on auth, pivot to billing with /compact Focus on billing-related decisions — keep the useful context, lose the rest.

/rewind

Open the menu with EscEsc or /rewind. Pick a past prompt, then choose what to restore.

Rewind to a prompt ↑ ↓ to navigate · Enter to select
⟩ refactor the token refresh helper 2m ago
  add tests for auth middleware 11m ago

  scaffold the session reducer 1h ago
Restore action 1–4 to pick
1 Restore code + conversation →
2 Restore conversation only →
3 Restore code only →
4 Summarize forward from here →

Caveat: tracks Claude's file edits only. Bash side effects and manual edits outside Claude are not rewound. Auto-cleaned after 30 days.

  • ~60 seconds.
  • Chord is double-Esc, or type /rewind — same menu either way.
  • Single fastest way to undo a wrong turn without restarting.
  • Menu is a scrollable list of every user prompt in this session, most recent on top.
  • You pick the prompt you want to go back to — not a named stage, the actual thing you typed.
  • Four actions:
    • Restore code and conversation together.
    • Restore just the conversation, keeping your current code.
    • Restore just the code, keeping the conversation.
    • Summarize forward from that point — a compact anchored to the prompt you picked.
  • Big caveat, call it out: only tracks Claude's file edits.
  • If Claude ran git reset, a migration, or dropped a table via bash — not rewound.
  • Same for anything you edited yourself outside the session.
  • Not a replacement for git.
  • Checkpoints persist across sessions and auto-clean after 30 days.
  • Reach for this when you are twenty turns down a wrong path — you do not have to be careful when you can go back.
