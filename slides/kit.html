Context grid .ctx-real .ctx-clear .ctx-compact-real

One shared 200-cell grid visual, three modes: /context (cells pop in, info panel fades), /clear (cells drain away in reverse), /compact (messages cells shrink away; summary cells fade in). Same mental model, one visual language.

/clear — cells drain away

Start with the grid filled (same data-fill as /context). On trigger, every non-free, non-autocompact cell fades and scales away in reverse order. The grid ends empty, ready for a fresh session.

/clear Context Usage
Opus 4.7 (1M context) us.anthropic.claude-opus-4-7[1m] 287k → 17.1k tokens
After /clear
⛶Free space:980.9k (98.1%)
⛝Autocompact buffer:17.1k (1.7%)

Benefits: no baggage, fresh session, faster responses.

/compact — messages coalesce into summaries

Sys-prompt / sys-tools / memory / skills stay put. The 54 messages cells shrink away; a handful of new summary cells (filled, with an inset ring) fade in at the start of the messages region. The total messages footprint drops by ~75%.

/compact Context Usage
Opus 4.7 (1M context) us.anthropic.claude-opus-4-7[1m] 287k → 95k tokens
After /compact
⛁System prompt:6.2k (unchanged)
⛁Memory files:812 (unchanged)
⛁Skills:956 (unchanged)
⛁Messages (summarized):60k (was 269.5k)

Typography utilities

For slides where the existing h1/h2 felt too big or too dull. Use .display-xxl as a hero thesis, .display-quote-lg as a pull-quote, .eyebrow as a cleaner kicker, and .tag-pill to inline command names in prose.

For slide 3 (the one-sentence thesis). Replaces the current 2.75rem treatment with a confident display scale.

.display-quote-lg — pull-quote

For slide 16 (the description rule). Narrower column, tighter leading, less overwhelming than the current h2.

Descriptions say when, never what.
